# DroidSeal · 安卓发布封签

**商业加固前,一键端到端发布安全。** —— 本地优先的安卓发布安全流水线:静态审计 → 加固 → 发布门禁——支持源码与 APK 双输入——提供 CLI / REST / TUI 三种形态。

## 功能

- **静态审计** —— **373 个源码检测器**(加密/网络/存储/组件/权限/输入输出/配置/生命周期/隐私合规/并发十维度)+ APK 清单/签名/DEX/ELF 检查 + **19 项污点分析** + **30 条行为规则** + **30 条离线供应链快照**——带**置信度分级、交叉证据与精度门禁**(确认后才报告)。
- **加固** —— **18+ 个源码接入生成器**:加壳(DEX 加密加载)、VMP 指令化、控制流平坦化、反调试 + ptrace、完整性与环境检测、运行时不留痕迹、死代码注入、原生(so)混淆、Dex2C 等。
- **发布门禁** —— pass/review/block 决策、证据包、CycloneDX SBOM、复测闭环、双模式与签名精审。
- **报告** —— 7 种格式、MASTG 逐项清单与 MASVS 级别、语义深度、加固建议、POC、历史对比。
- **动态交叉验证** —— adb 桥接提供 **8 个运行期信号**(设备矩阵/定向 logcat/UI 冒烟/崩溃·ANR/多设备)——回附加到静态发现。
- **基准驱动** —— 30 用例评测器输出精度/召回——支持外部 DroidBench/OWASP 目录。

## 快速开始

```bash
npm install -g droidseal          # 或: bun x droidseal
droidseal audit <源码或APK>        # 一条命令,端到端
droidseal one-click               # TUI:审计 → 加固 → 发布门禁
```

## 平台

- 运行平台:Windows x64、Linux x64。
- 运行时依赖:**零**。第三方包仅限开发期;外部工具(adb/apksigner/zipalign/aapt/dexdump/keytool/java/unzip)以用户侧 CLI 调用——不嵌入、不分发。

## 安全边界

- **本地优先** —— 无上传、无模型调用;供应链检查为离线快照。
- **源码接入加固** —— 生成器构建期生效;不事后改写未知 APK。
- **运行时只报告** —— 反调试桩只报告不阻断——除非显式启用 EXIT。

## 创新点

确认后才报的精度语义、审计 → 加固 → 门禁闭环、商业级 VMP/Dex2C 之外最广的源码接入加固集、零运行时依赖、本地优先隐私、静态-动态交叉验证。
